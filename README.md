# Campus Leave Portal — Student Leave Application System

A no-login student leave application system built with plain HTML/CSS/JS and Firebase Firestore.

## Folder structure
```
StudentLeaveApp/
├── index.html        Public student leave form
├── admin.html         Admin login page
├── dashboard.html      Admin dashboard
├── style.css          Shared styles
├── script.js          Student form logic
├── admin.js           Admin login logic (fixed credentials)
├── dashboard.js        Dashboard data + actions
├── firebase.js         Firebase config + init
└── assets/            (optional images/icons)
```

Default admin login: **admin / Admin@123** (change in `admin.js`).

See the chat response for full setup, Firestore, and deployment instructions.
